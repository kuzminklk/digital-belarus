# AGENTS.md

## Goal

Maintain and extend «Цифровая Беларусь» — a trilingual (ru, be, en) marketing site for a digital services studio in Minsk. The site sells websites, Telegram bots, AI assistants, e-commerce and automation. It is a single landing page plus a privacy page, statically rendered, with no backend or customer data storage.

## Stack

- Next.js 16 App Router, React 19, TypeScript strict, Turbopack.
- next-intl 4 for locale routing, metadata and message catalogues.
- Hand-written CSS Modules and CSS custom properties. No Tailwind, no UI kit.
- Handjet pixel mono for interface/body text; **pixel-serif display headings are generated PNG masks** (`public/type/**`, `src/content/pixel-type.json`) produced by `scripts/generate-pixel-type.py` from Cormorant Garamond. Run it after changing any heading copy.
- Imagery is 1-bit dithered PNG (`public/pixel/**`) generated by `scripts/generate-pixel-images.py` from public-domain/CC sources; see `docs/design/image-credits.md`.
- Vitest for pure logic. No end-to-end framework is installed.
- Deployment: Vercel, static/ISR output.

## Commands

```bash
pnpm dev             # local development, redirects / → a detected locale
pnpm build           # production build for all locales
pnpm start           # serve the production build
pnpm typecheck       # tsc --noEmit
pnpm lint            # eslint .
pnpm check:i18n      # message parity across ru/be/en
pnpm test            # vitest run
pnpm check           # all of the above
pnpm format          # prettier --write .
python3 scripts/generate-pixel-type.py    # regenerate heading masks after copy changes
python3 scripts/generate-pixel-images.py  # regenerate dithered imagery
python3 scripts/generate-og.py            # regenerate Open Graph images
python3 scripts/generate-brand-assets.py  # regenerate favicon/app icons
```

## Conventions

**Language policy.** User-facing copy is Russian, Belarusian and English. Code, comments, commits, README, AGENTS and all documentation are English. Russian (`messages/ru.json`) is the source catalogue; `be.json` and `en.json` mirror its structure exactly.

**Content belongs in `messages/`.** Do not hardcode user-facing copy in components. Arrays and objects that describe content are read with `t.raw()` and typed locally. Brand names, product names and decorative Latin instrument labels are the only exceptions.

**Structure and styling.** One section per file in `src/components/sections/`, one CSS Module next to it. Compose shared primitives from `src/styles/components.css` (`.btn`, `.panel`, `.tag`, `.field`, `.mono`, `.container`, `.section`, `.on-paper`). Reference design tokens from `src/styles/tokens.css`; never hardcode colours, type sizes, spacing or motion durations.

**Design rules — v2 warm two-tone.**

- Exactly two colours: warm ink `#12100d` and cream `#ebe2d1`. **No red, green, gold, blue or grey-blue accents.** Hierarchy comes from scale, inversion, texture and hairlines.
- Sections alternate full ink and full cream (`.on-paper`). Header/footer stay ink.
- Display headings use the generated pixel-serif masks through `PixelType` / `SectionHeading` `typeName`; never substitute a smooth display font or letter-spaced serif text.
- Interface and body copy use Handjet (pixel mono), uppercase for labels/buttons/navigation, sentence case for paragraphs. Body sizes ~17–19 px, line-height 1.5–1.6.
- Imagery is dithered 1-bit pixel art. Never add stock photos, gradients, glow, soft shadows or rounded cards. Use 0–2 px corners, 1 px hairlines.
- The pixel stamp (cream square + ink star) is the only logo. Decorative SVG is `aria-hidden`.
- Motion is restrained: reveal fades, a short underline draw, the tiny scroll cue. Respect `prefers-reduced-motion`.

**Accessibility.** Semantic landmarks, one `h1` per page, visible focus states, keyboard-operable dialogs and accordions, `aria-live` for async feedback, WCAG AA contrast, `prefers-reduced-motion` respected for every non-essential animation. Do not remove the skip link. Generated heading masks must always have real text in the DOM (PixelType emits an `.sr-only` copy).

**Performance.** No new runtime libraries for effects; use CSS and small client components. Preload only the Cyrillic and Latin Handjet subsets. Avoid external requests: no CDN fonts, no analytics, no third-party scripts. Pixel masks/images are static and cacheable.

**i18n.** Locale routing uses `localePrefix: 'always'`, default locale `ru`. Add a key to all three catalogues at once and run `pnpm check:i18n`. Preserve ICU placeholders and array lengths across locales. Metadata must be locale-specific and include canonical + hreflang alternates. If a heading changes, regenerate the pixel-type manifest.

**Security and privacy.** No cookies, analytics or storage besides the language in the URL. The brief form builds a message in the browser, copies it and opens Telegram; it never posts data to a server. Never commit secrets; deployment credentials live outside the repository.

**Git.** Work is committed in small, descriptive commits in English. Do not commit `.next`, `node_modules`, `.env*`, `.cache`, local screenshots or generated test output. The repository is a submodule of `kuzminklk/artificial-intelligence` at `web/digital-belarus`.
