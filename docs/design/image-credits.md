from the sources below. Every photograph is reduced to a 1-bit dithered print in
the two brand inks (`#12100d` and `#ebe2d1`). This file is the licence record:
update it whenever a source, crop or generated asset changes.

## Pipeline and parameters

`scripts/generate-pixel-images.py` performs, per asset: crop → grayscale →
autocontrast → optional contrast stretch (“levels”) → resize to a low pixel grid
→ optional blur → gamma search until the ink coverage target is reached →
Floyd–Steinberg 1-bit dither → palette to ink/cream → nearest-neighbour upscale.

Target ink coverage is measured on the 1-bit bitmap before colourising. Photos
on ink use high coverage (62–70% ink, cream highlights); engravings on cream use
low coverage (28–30% ink); the portrait sits in between.

## Reproducing the assets

```bash
# 1. Regenerate the two-tone image set (downloads missing sources into .cache)
python3 scripts/generate-pixel-images.py

# 2. Regenerate the mark, favicon and app icons
python3 scripts/generate-brand-assets.py

# 3. Regenerate the pixel-serif display masks (site headings)
python3 scripts/generate-pixel-type.py

# 4. Regenerate the OG previews (needs public/pixel/hero-lunar.png)
python3 scripts/generate-og.py
```

The scripts are deterministic apart from the source files: do not edit the
`public/pixel/*.png` outputs by hand — edit the crop/density table above, rerun
the pipeline, and update this document.

## Replacing a source

1. Confirm the licence allows commercial use and adaptation; add the new source
   and author to this document before committing the asset.
2. Add the path/URL and a crop to `SOURCES` in
   `scripts/generate-pixel-images.py`.
3. Run the pipeline and inspect the result at 100% zoom (the dither must stay
   legible at its rendered size).
4. If the image is CC BY-SA or contains attribution requirements, add the
   credit to the site (footer/credits/case caption) in the same change.
