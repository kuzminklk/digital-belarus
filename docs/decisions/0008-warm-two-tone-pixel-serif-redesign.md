# 0008 — Warm two-tone pixel-serif redesign (v2)

Status: accepted
Date: 2026-11-26
Supersedes: [0005](0005-belarus-constellation-hero.md) (hero visual), and the palette/typography parts of [0004](0004-pixel-ornament-system.md)

## Context

V1 was technically sound but visually generic: cold blue-black, Cormorant + Manrope + JetBrains Mono, red and aurora-green accents, glow gradients and card grids. The client asked for a design system closer to the NOCTRA observatory reference: monochrome, warm, two-coloured, with sophisticated pixel-art typography and imagery, and more harmony.

## Decision

Rebuild the visual layer as a strict warm two-tone system:

- **Colour:** only warm ink `#12100d` and cream `#ebe2d1`; no accent hues. Inverted cream sections alternate with ink ones.
- **Display type:** custom pixel-serif masks generated from Cormorant Garamond by `scripts/generate-pixel-type.py` (tiny render → threshold → nearest upscale). Headings use real text for accessibility plus a mask for paint.
- **UI/body type:** Handjet variable pixel mono, self-hosted with Cyrillic/Belarusian subsets.
- **Imagery:** 1-bit Floyd–Steinberg dithered, nearest-upscaled PNGs from public-domain/CC sources, generated by `scripts/generate-pixel-images.py`.
- **Layout:** editorial hairlines, numbered rows, full-bleed image bands, inversion instead of cards/glow.
- **Identity:** cream square stamp with an ink pixel rushnyk star; thin rushnyk rules.

## Consequences

- The identity now feels like one archival object and directly answers the reference.
- Headings are raster masks: changing copy requires regenerating `public/type` (documented, scripted). Masks are word-shape assets, not a text font, so we must always keep the real string in the DOM.
- Handjet at body sizes is characterful but less conventional; readability was verified at 390/1440 px.
- Image sources and licences must be tracked; the dither pipeline lives in the repo.
- Future colour requests should be challenged: two-tone is the concept, not an accident.

## Alternatives considered

- Keep the serif and only recolor — not enough differentiation.
- Use a commercial pixel serif font — Cyrillic coverage is rare and licensing adds cost; generating masks from an OFL serif is reproducible and has full coverage.
- Photo-real monochrome imagery — the brief asks for pixel art; dithering unifies sources and keeps the two-tone constraint.
- Dark-only with a single accent — the client explicitly asked for warm/two-colour.
